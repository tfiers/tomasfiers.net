All curves come from the makers' own published graphs, both the frequency responses and the polar plots. Where the PDF contains a graph as vector data, the curve is read out exactly; otherwise it's traced from the image (to within about 0.5 dB for response curves and 1 dB for polar plots). Values at standard frequencies

Curves are shifted so that 1 kHz sits at the mic's published sensitivity: higher = more output for the same sound. Mics without a published sensitivity are hidden.

Mics

  • Sensitivity: the output voltage for a 94 dB SPL (1 Pa) tone at 1 kHz. Higher means less preamp gain is needed.
  • Self-noise: the noise the mic itself generates, A-weighted: filtered the way our hearing works, so low rumble and the highest frequencies count less.
  • Max SPL: the loudest sound before distortion, as the maker specifies it (their distortion threshold varies).
  • – means the maker doesn't publish it.

Where do I get the data?

From a spec sheet graph: screenshot the manufacturer's curve, open it in WebPlotDigitizer, set a log X axis, trace the line, and export CSV.

Measure it yourself: put a calibrated measurement mic in front of a speaker and run a sweep in REW (with the mic's calibration file loaded). Then put each of your mics in exactly the same spot and sweep again. In REW, divide each mic's sweep by the measurement-mic one (All SPL → Trace arithmetic → A / B): the speaker and the room are the same in both, so they cancel out and only the mic's own response is left. Export that as text and drop it here.
