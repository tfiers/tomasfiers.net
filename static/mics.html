Where to get data

From a spec sheet graph: screenshot the manufacturer's curve, open it in WebPlotDigitizer, set a log X axis, trace the line, and export CSV.

Measure it yourself: put a calibrated measurement mic in front of a speaker and run a sweep in REW (with the mic's calibration file loaded). Then put each of your mics in exactly the same spot and sweep again. In REW, divide each mic's sweep by the measurement-mic one (All SPL → Trace arithmetic → A / B): the speaker and the room are the same in both, so they cancel out and only the mic's own response is left. Export that as text and drop it here.

Make your own Mic Atlas

Mics added here stay in your browser. To put mics in the built-in library, make your own copy: the whole thing is one page (mics.html) and one data file (mics-library.js), in this site's public repository. Fork it, or download those two files (plus the mics-* image folders) and open mics.html in a browser.

Each mic is one entry in mics-library.js; the top of that file explains the fields. The mics here were added with an AI coding assistant (Claude Code): give it the manufacturer's data sheet or manual (PDF) and ask it to add the mic. It reads the frequency response and polar plots straight from the PDF's vector graphics where possible, or traces them from the image. The scripts that extracted the data for the mics here are in tools/mic-atlas.
