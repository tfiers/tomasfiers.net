Specs

From the manufacturers' data sheets. Sensitivity: output voltage for 1 Pa (94 dB SPL); ~16 dB between a condenser and a dynamic mic means that much more preamp gain. Self-noise is A-weighted; – = not published.

      Or drop CSV/TXT files here (one mic per file) —

      Two columns: frequency (Hz) and level (dB). Commas, tabs, semicolons or spaces all work; header and comment lines are skipped. REW exports, .frd files and WebPlotDigitizer CSVs load as-is.

      Where do I get the data?

      From a spec sheet graph: screenshot the manufacturer's curve, open it in WebPlotDigitizer, set a log X axis, trace the line, and export CSV.

      Measure it yourself: put each mic in the same spot in front of a speaker, run a sweep in REW, and export "measurement as text". A shared room and speaker cancel out once you use "Relative to" against one reference mic.
